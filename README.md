# MealToday | Responsive Food Delivery Landing Page

## Overview

MealToday is a responsive food-delivery-themed landing page developed using HTML and CSS in August 2024.

The project focuses on frontend interface design, responsive layouts, and adapting webpage components to different screen sizes using CSS media queries.

It was developed as a hands-on frontend practice project, exploring how to structure and style a food delivery website interface.

## Live Demo

[View MealToday](https://sagnikagoswami.github.io/mealtoday-responsive-landing-page/)

## Features

- Food delivery-themed landing page with custom branding.
- Navigation bar with location search, food search, and login interface.
- Hero section with introductory text and food imagery.
- Delivery and pickup selection interface.
- Address input and Find Food button design.
- Responsive layout adjustments for different screen widths.
- Custom CSS styling, typography, icons, and hover effects.

**Note:** This project is a frontend UI prototype. Search, login, delivery selection, and food ordering functionality are not implemented.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- Google Fonts
- Font Awesome

## Project Structure

- `index.html` – Main landing page structure.
- `css/style.css` – Base styling and layout.
- `css/phone.css` – Responsive styles for screens between 601px and 750px.
- `css/phone2.css` – Responsive styles for screens up to 600px.
- `css/small_screen3.css` – Responsive styles for screens between 751px and 890px.
- `css/small_screen2.css` – Responsive styles for screens between 891px and 934px.
- `css/small_screen.css` – Responsive styles for screens 935px and above.
- `assets/` – Images and other visual assets.

## Concepts Practiced

- Structuring webpages using semantic HTML elements.
- Building layouts with CSS Flexbox.
- Creating responsive interfaces using media queries.
- Styling navigation bars, input fields, buttons, and content sections.
- Using CSS custom properties for consistent colors.
- Adjusting element positioning, dimensions, and typography for different screen sizes.
